# mmd-renderer

MMD 的 React 渲染器，根据元数据生成列表、详情和表单。支持中英文、响应式布局、自定义字段与按钮，以及 API、认证、路由和错误处理配置。

```bash
npm install mmd-contracts mmd-renderer react react-dom antd
```

React、React DOM 和 Ant Design 由宿主项目提供。当前示例验证于 React 19、Ant Design 6。
