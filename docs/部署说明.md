# 部署说明

生产环境由 GitHub Actions 部署，不在开发机直接执行生产发布脚本。

## 架构

```text
mmd.zyking.xyz
└── Next.js 静态导出 → Cloudflare Workers Static Assets

mmd-api.zyking.xyz
└── Hono Worker → PrismaPg → Hyperdrive → Neon PostgreSQL
```

## GitHub Secrets

仓库需要配置：

- `NPM_TOKEN`：npm 发布权限，先发布可安装版本再部署官网。
- `CLOUDFLARE_API_TOKEN`：具备 Workers 发布和 Hyperdrive 写入权限。
- `DATABASE_URL`：Neon Direct 连接串，仅用于 Prisma migration 和 Hyperdrive 配置同步。

生产 Worker 不保存 `DATABASE_URL` Secret。Cloudflare 账号 ID 和 Hyperdrive ID 写入 Wrangler 配置；数据库连接字符串不得写入源码、日志或构建产物。

## Hyperdrive

Hyperdrive 使用 Neon 未开启 pooling 的 Direct endpoint，Worker 通过 `HYPERDRIVE` binding 获取动态连接串。Demo 要求写后立即读，因此 Hyperdrive 必须关闭查询缓存。

首次部署前，手动运行 GitHub Actions 的 `Deploy MMD Production`，选择 `configure-hyperdrive`。已有资源仅在明确选择 `update-hyperdrive` 时修改。取得工作流摘要中的 ID 后，将其提交到 `apps/demo-api/wrangler.jsonc`。日常 `deploy` 不修改 Hyperdrive 配置。

```jsonc
"hyperdrive": [
  {
    "binding": "HYPERDRIVE",
    "id": "<HYPERDRIVE_ID>"
  }
]
```

本地 Bun 直接使用 `DATABASE_URL`。本地 Worker 使用：

```bash
export CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE="$DATABASE_URL"
bun --cwd=apps/demo-api run dev:worker
```

## API 配置

`apps/demo-api/wrangler.jsonc` 设置：

- 自定义域名 `mmd-api.zyking.xyz`。
- CORS 来源 `https://mmd.zyking.xyz`。
- Hyperdrive binding `HYPERDRIVE`。
- 每个来源 IP 每分钟 120 次 API 请求的统一限流。

生产会话由 Cloudflare 来源 IP 的哈希摘要生成，客户端不能伪造会话。Neon 触发器原子限制每个会话最多 50 条 Product，避免并发写入绕过应用层检查。

部署流程先使用 GitHub Secret `DATABASE_URL` 执行 Prisma migration，再发布带 Hyperdrive binding 的 Hono Worker。发布流程不再向 Worker 同步数据库 Secret。发布后验证：

```bash
curl https://mmd-api.zyking.xyz/health
curl https://mmd-api.zyking.xyz/openapi.json
```

## 网站配置

Next.js 使用 `output: "export"` 生成静态目录。`apps/website/wrangler.jsonc` 通过 Static Assets 托管导出文件并绑定 `mmd.zyking.xyz`。

生产构建默认请求：

```text
https://mmd-api.zyking.xyz/api
```

也可在构建时通过 `NEXT_PUBLIC_MMD_API_URL` 覆盖。

## 发布验证

1. GitHub Actions 的测试、类型检查和构建全部通过。
2. 数据库迁移成功，API `/health` 返回 `{"status":"ok"}`。
3. `/docs` 可打开，`/openapi.json` 为 OpenAPI 3.1。
4. 官网首页、文档、示例和 Playground 可加载。
5. Playground 可新建、编辑、复制和删除 Product。
6. 不同来源网络看不到其他会话写入的数据，数据库拒绝第 51 条 Product。
7. 创建或更新后立即查询到最新数据，确认 Hyperdrive 缓存已关闭。
8. 官网在常见桌面、平板和手机尺寸可用；移动端导航、表格、弹窗和操作按钮无裁切。

## 版本、文档和 Demo 同步

`main` 的生产工作流调用 npm 发布工作流，先通过发布门禁、静态网站浏览器测试和公共 npm 安装验证，再部署 API 与网站。每次部署前通过 `wrangler whoami` 验证 Cloudflare 身份；线上浏览器验收通过后创建 `v<版本>` GitHub Release，内容来自 `CHANGELOG.md`。

官网 `/changelog/` 展示版本及文档/demo 入口，`/playground/embedded/` 覆盖内嵌 CRUD、筛选、ID、关联、生命周期与 JSON。原 `/playground/` 展示数据库链路。日常新增功能按 [npm 发布规则](./npm发布.md) 同步维护这几个入口。

```bash
# 已完成 bun install 和 build；本地需要 Chrome，CI 安装 Playwright Chromium。
MMD_TEST_BASE_URL=https://mmd.zyking.xyz bun run test:browser
```
