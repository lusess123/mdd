# 扩展开发

## 自定义字段

模型通过 `type` 指定字段渲染器名称：

```ts
{
  name: "inventory",
  label: "Inventory",
  fieldType: ModelFieldType.Number,
  type: "inventory-meter",
  required: true,
  list: true,
}
```

前端为列表、详情、表单和搜索场景注册组件：

```tsx
import { InputNumber, Progress } from "antd";
import {
  MmdProvider,
  type FieldRendererProps,
} from "mmd-renderer";

function InventoryMeter({
  value,
  scene,
  disabled,
  onChange,
}: FieldRendererProps<number>) {
  const count = Number(value ?? 0);
  if (scene === "form" || scene === "search") {
    return (
      <InputNumber
        min={0}
        precision={0}
        value={count}
        disabled={disabled}
        onChange={(next) => onChange?.(next ?? 0)}
      />
    );
  }
  return <Progress percent={Math.min(100, count * 2)} />;
}

<MmdProvider
  fields={{
    "inventory-meter": {
      list: InventoryMeter,
      detail: InventoryMeter,
      form: InventoryMeter,
      search: InventoryMeter,
    },
  }}
>
  {children}
</MmdProvider>;
```

完整代码见[库存字段示例](../examples/custom-fields/库存字段.tsx)。

## 自定义操作

先在模型声明操作。`showExpression` 只能读取当前 `row`，用于控制行按钮是否显示。

```ts
actions: [
  {
    name: "publish",
    label: "Publish",
    placement: "row",
    tone: "primary",
    showExpression: 'row.status === "draft"',
  },
  {
    name: "duplicate",
    label: "Duplicate",
    placement: "row",
    confirm: true,
  },
];
```

服务端注册同名处理器：

```ts
import { MmdEngine, MmdRegistry, type MmdActionHandler } from "mmd-engine";

const publish: MmdActionHandler = async ({ ids, engine, model }) => {
  const data = await Promise.all(
    ids.map((id) =>
      engine.save({ model: model.name, id, data: { status: "published" } }),
    ),
  );
  return { affected: data.length, data };
};

const engine = new MmdEngine({
  registry: new MmdRegistry().registerModel(productModel),
  adapter,
  actions: { publish },
});
```

默认前端处理器会调用 `/api/mmd/actions/:action` 并刷新列表。需要弹窗、跳转或额外参数时，可覆盖前端处理器：

```tsx
<MmdProvider
  actions={{
    duplicate: async (context, action) => {
      const id = String(context.record?.[context.keyField ?? "id"]);
      const data = await context.client.executeAction({
        model: context.model,
        action: action.name ?? "duplicate",
        ids: [id],
      });
      return { data, refresh: true };
    },
  }}
>
  {children}
</MmdProvider>
```

完整代码见[自定义操作示例](../examples/custom-actions/README.md)。

## Provider 配置

以下配置项相互独立，可只覆盖需要的一项：

```tsx
<MmdProvider
  api={{
    baseUrl: "https://api.example.com/api",
    timeoutMs: 8_000,
    credentials: "include",
    headers: { "X-App": "admin" },
  }}
  auth={{
    mode: "custom",
    getToken: () => sessionStorage.getItem("token"),
    getHeaders: () => ({ "X-Tenant": "tenant-a" }),
  }}
  router={{
    mode: "custom",
    navigate: (path) => window.history.pushState(null, "", path),
  }}
  locale="zh-CN"
  messages={{
    "zh-CN": { "actions.publish": "立即发布" },
    "en-US": { "actions.publish": "Publish now" },
  }}
  onError={(error) => reportError(error)}
  onSuccess={(message) => console.info(message)}
>
  {children}
</MmdProvider>
```

还可通过 `api.request` 替换整个请求函数，通过 `api.paths` 映射已有后端路径，或直接传入自定义 `MmdClient`。

完整代码见[Provider 示例](../examples/custom-provider/自定义配置.tsx)。

## 页面插槽

```tsx
<MmdRenderer
  model="Product"
  view="listview"
  slots={{
    beforeView: <CampaignBanner />,
    afterContainer: ({ model }) => <small>{model?.name}</small>,
    empty: <Empty description="No products" />,
  }}
/>
```

可用插槽为 `beforeView`、`afterView`、`beforeContainer`、`afterContainer`、`loading`、`error`、`empty`。

## 数据库适配器

业务数据库只需实现：

```ts
interface MmdDataAdapter {
  findMany(input: AdapterFindManyInput): Promise<Record<string, unknown>[]>;
  count(input: AdapterCountInput): Promise<number>;
  findOne(input: AdapterFindOneInput): Promise<Record<string, unknown> | null>;
  create(input: AdapterCreateInput): Promise<Record<string, unknown>>;
  update(input: AdapterUpdateInput): Promise<Record<string, unknown>>;
  remove(input: AdapterRemoveInput): Promise<Record<string, unknown> | null>;
}
```

Adapter 必须自行落实租户或会话隔离。Demo 的 Prisma Adapter 会把每个查询限定在 `sessionId`。
