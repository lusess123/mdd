# 快速开始

## 1. 安装三个核心包

选择当前项目使用的包管理器，执行其中一条命令：

```bash
npm install mmd-contracts mmd-engine mmd-renderer
pnpm add mmd-contracts mmd-engine mmd-renderer
yarn add mmd-contracts mmd-engine mmd-renderer
bun add mmd-contracts mmd-engine mmd-renderer
```

## 2. 启动仓库示例

需要 Bun 1.3 或更高版本。

```bash
git clone https://github.com/lusess123/mdd.git
cd mdd
bun install
export DATABASE_URL='postgresql://...'
bun --cwd=apps/demo-api run db:migrate
bun run dev
```

打开：

- Playground：<http://localhost:3000/playground>
- Hono API：<http://localhost:8787>
- API 文档：<http://localhost:8787/docs>

`DATABASE_URL` 是本地 Bun 运行和 Prisma migration 的必填项，Demo API 不会回退到内存数据。不要提交连接字符串。

生产 Worker 通过 `HYPERDRIVE` 绑定访问 Neon，不读取 `DATABASE_URL`。使用 `wrangler dev` 时，通过 Wrangler 推荐的本地覆盖变量传入同一连接串：

```bash
export DATABASE_URL='postgresql://...'
export CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE="$DATABASE_URL"
bun --cwd=apps/demo-api run dev:worker
```

## 3. 定义模型

```ts
import { ModelFieldType, type ModelDefinition } from "mmd-contracts";

export const productModel = {
  name: "Product",
  label: "Product",
  primaryKey: "id",
  fields: [
    { name: "id", fieldType: ModelFieldType.Key, readOnly: true },
    {
      name: "name",
      label: "Name",
      fieldType: ModelFieldType.Text,
      type: "text",
      required: true,
    },
    {
      name: "price",
      label: "Price",
      fieldType: ModelFieldType.Number,
      type: "money",
      required: true,
    },
  ],
} satisfies ModelDefinition;
```

`mmd-engine` 会根据字段声明限制查询和写入，`mmd-renderer` 会生成对应的列表、搜索、详情和表单。

## 4. 创建服务端引擎

```ts
import { MmdEngine, MmdRegistry, type MmdDataAdapter } from "mmd-engine";
import { productModel } from "./product-model";

export function createEngine(adapter: MmdDataAdapter) {
  const registry = new MmdRegistry().registerModel(productModel);
  return new MmdEngine({ registry, adapter });
}
```

数据库只需实现 `MmdDataAdapter` 的六个方法。仓库内提供 `PrismaPg + Hyperdrive + Neon` 的可运行实现；[内存实现](../apps/demo-api/src/memory-adapter.ts)仅用于示例和测试，不参与运行时回退。

## 5. 渲染 React 页面

```tsx
"use client";

import { MmdProvider, MmdRenderer } from "mmd-renderer";

export function ProductPage() {
  return (
    <MmdProvider>
      <MmdRenderer model="Product" view="listview" />
    </MmdProvider>
  );
}
```

零配置时，Provider 请求同源 `/api/mmd/*`、使用匿名认证、携带同源 Cookie，并使用 Hash 路由；界面内置中英文，按浏览器语言选择，无法识别时回退中文。

Demo 前后端分属不同域名，因此显式设置 API 地址：

```tsx
<MmdProvider
  api={{
    baseUrl: "https://mmd-api.zyking.xyz/api",
    credentials: "include",
  }}
>
  <MmdRenderer model="Product" view="listview" />
</MmdProvider>
```

渲染器覆盖常见桌面、平板和手机尺寸。移动端使用底部导航，表格允许横向浏览，弹窗限制在可视区域内，主要操作始终可触达。
