# MMD 开源项目需求

## 定位

MMD 是元数据驱动的全栈管理工具。开发者定义模型、字段和操作后，即可获得安全的数据 API 与 React 管理界面，并可替换数据库、字段组件和业务操作。

## 交付物

- `mmd-contracts`：模型、字段、视图、字典、Action 和请求协议。
- `mmd-engine`：元数据、查询、分页、过滤、写入和自定义操作。
- `mmd-renderer`：Provider、列表、详情、表单、字段注册、操作注册和页面插槽。
- Hono Demo API：通用接口、Product REST 别名、OpenAPI 和 API 文档。
- Next.js 静态网站：中英文官网、文档、示例和真实 Playground。
- 可复制示例：前后端、自定义字段、自定义操作和 Provider 覆盖。

## 架构

```text
ModelDefinition
    ├── mmd-engine ── MmdDataAdapter ── PrismaPg ── PostgreSQL
    └── mmd-renderer ── MMD API ── Hono

生产：Cloudflare Worker ── HYPERDRIVE ── Neon
本地：Bun ── DATABASE_URL ── Neon 或 PostgreSQL
```

引擎不绑定 Hono、Prisma 或 Cloudflare，数据库通过 `MmdDataAdapter` 注入。可运行的 Demo 必须连接 PostgreSQL，不提供内存回退；内存 Adapter 仅用于示例和测试。

## 核心能力

- 根据模型生成列表、搜索、详情、新建和编辑视图。
- 只允许访问已声明字段，拒绝写入主键、只读字段和未知字段。
- 支持分页、排序及 `eq`、`contains`、`in`、`gte`、`lte` 过滤。
- Action 必须先在模型声明并在服务端注册。
- API 错误统一为 `{ error: { code, message, details? } }`。

## 前端配置

`MmdProvider` 零配置默认提供：

- API：原生 `fetch` 请求同源 `/api`，超时 10 秒。
- 认证：匿名访问并携带同源 Cookie。
- 路由：Hash 路由。
- 错误：统一处理超时、网络和 API 错误。
- 国际化：内置 `zh-CN`、`en-US`，按浏览器语言选择。

使用方可覆盖 API 地址、请求函数、Token/Header、路由、错误回调、语言和文案。跨域 Demo 使用 `credentials: "include"`。

## 扩展示例

- 自定义字段：`inventory-meter` 在列表显示库存进度，在表单使用数字输入框。
- 字段类型：图片、金额、标签、状态、文本、数字和日期时间。
- 自定义操作：发布、归档、复制，支持行操作、批量操作、显示条件、确认和刷新。
- 后端：Hono 调用 `mmd-engine`，Prisma Adapter 负责 PostgreSQL 数据访问。
- 页面插槽：视图、容器、加载、错误和空状态前后可注入 React 内容。

## Demo 与数据

Product Demo 覆盖 CRUD、搜索、状态、库存、发布、归档和复制。生产数据存储在 Neon；会话使用 Cloudflare 来源 IP 的哈希隔离，本地支持 Cookie 或 `X-MMD-Session`。公开 API 按来源 IP 限流，数据库原子限制每个会话最多 50 条 Product。

## 官网与响应式

官网用于推广 MMD 库，不介绍 Demo 站点自身的运行方式。外壳采用手绘漫画风格，表格、表单和弹窗保持标准 Ant Design 风格。首页使用真实 `MmdRenderer`；文档聚焦接入、Provider、字段、Action、Hono 和 API；Playground 展示真实请求、响应及前后端代码。

页面覆盖常见桌面、平板和手机尺寸：

- 导航在移动端切换为底部导航，并保留当前项状态。
- 表格在窄屏可横向浏览，操作列保持可触达。
- 弹窗不得超出视口，小屏使用安全边距或全屏布局。
- 表单、代码块和主要操作不得裁切或溢出。

## 运行与部署

- 本地运行时：Bun，使用 `DATABASE_URL`。
- API：Hono，部署到 Cloudflare Workers。
- 数据访问：`PrismaPg + pg`。
- 生产连接：Cloudflare `HYPERDRIVE` binding 连接 Neon Direct endpoint。
- 本地 Worker：使用 `CLOUDFLARE_HYPERDRIVE_LOCAL_CONNECTION_STRING_HYPERDRIVE`。
- 前端：Next.js `output: "export"`，部署到 Cloudflare Workers Static Assets。
- 域名：`mmd.zyking.xyz`、`mmd-api.zyking.xyz`、`mmd-api.zyking.xyz/docs`。
- 发布：只通过 GitHub Actions。

Hyperdrive 必须关闭查询缓存，保证写后立即读。Action 的独立操作负责首次创建或显式更新，日常发布使用 Wrangler 中固定的 binding ID。GitHub Secret `DATABASE_URL` 仅用于 Prisma migration 和 Hyperdrive 配置，不注入生产 Worker。密钥不得进入仓库、日志或构建产物。

## 包名与发布

公共包名为 `mmd-contracts`、`mmd-engine`、`mmd-renderer`。2026-07-15 查询时均未注册；发布前必须再次检查。产物不得包含 `workspace:*` 或私有依赖，React、React DOM、Ant Design 等宿主库使用 `peerDependencies`。先发布 beta，再升级稳定版本。

## 首期不做

- 不迁移 Cookiy 专用 Controller、权限和业务组件。
- 不把引擎绑定到特定 ORM 或 Web 框架。
- 不提供管理员或跨会话数据访问。
- 不承诺复杂关系字段、跨数据库事务或完整 RBAC。

## 验收标准

- 三个包无 Cookiy/Vovey 私有依赖，可独立类型检查和测试。
- Hono API 本地通过 `DATABASE_URL` 运行，无内存回退。
- 生产 Worker 只通过 `HYPERDRIVE` 访问 Neon，支持完整 CRUD 和 Prisma 事务。
- Product CRUD、自定义库存字段、发布、归档和复制均可操作。
- API、认证、路由、错误和中英文文案可覆盖，零配置默认可工作。
- 数据按会话隔离，限流和 50 条记录上限有效，写后立即读到最新结果。
- 官网、文档、Playground 和代码示例在主要桌面、平板和手机尺寸可用。
- GitHub Actions 完成测试、类型检查、构建、迁移、部署和线上验证。
- npm 发布前重新检查包名，确认产物不含工作区或私有依赖。
