# 功能简述

MMD 将模型协议、服务端执行和 React 渲染拆成三个包，使外部项目无需依赖 Cookiy 内部模块即可获得完整管理界面。

## 本次范围

- 实现 `mmd-contracts`、`mmd-engine`、`mmd-renderer`。
- 提供 Hono + Prisma + Neon 的 Product Demo 后端。
- 提供 Next.js 静态官网、文档、示例和 Playground。
- 支持 API、认证、路由、错误处理和中英文文案的默认值与覆盖。
- 提供自定义库存字段及发布、归档、复制操作示例。
- 生产会话使用 Cloudflare 来源 IP 哈希，本地使用 Cookie 或 `X-MMD-Session`。
- 公开 API 每个来源 IP 每分钟限制 120 次请求，Neon 原子限制每个会话 50 条 Product。
- 官网用于推广 MMD 库，不介绍 Demo 站点自身的运行方式；首页与 Playground 均展示标准风格的真实 `MmdRenderer`。

## 结果

开发者可从一个 `ModelDefinition` 生成元数据、CRUD API 和 React 列表/详情/表单，并通过 Adapter、字段注册器和 Action 注册器接入自身数据库与业务逻辑。
